# Design Rule Categories

The 12 categories that `design.md` must cover. Each category has tokens (structured data) and prose (narrative rules).

## 1. Colors
- **Tokens:** Full MD3 color scheme (surface, primary, secondary, tertiary, error, neutral, neutral-variant)
- **Prose:** Color philosophy, usage rules, accent strategy, contrast requirements

## 2. Typography
- **Tokens:** Type scale (display-xl, headline-lg, headline-md, body-lg, body-sm, label-mono, label-code)
- **Prose:** Font pairing rationale, hierarchy rules, readability constraints

## 3. Spacing
- **Tokens:** Unit, gutter, margin-mobile, margin-desktop, container-max
- **Prose:** Spacing rhythm, density guidelines, responsive adaptation

## 4. Layout
- **Tokens:** Grid columns, breakpoints, containment strategy
- **Prose:** Grid system philosophy, responsive behavior, content flow

## 5. Elevation
- **Tokens:** Depth levels (flat vs. elevated)
- **Prose:** Depth conveyance method (color inversion, shadows, borders)

## 6. Shapes
- **Tokens:** Border radius, border style
- **Prose:** Shape language, structural framing, corner treatment

## 7. Components
- **Tokens:** Component-specific tokens (button styles, card padding, input borders)
- **Prose:** Component behavior rules, state transitions, interaction patterns

## 8. Motion
- **Tokens:** Transition durations, easing curves
- **Prose:** Animation philosophy, scroll behavior, micro-interactions

## 9. Accessibility
- **Tokens:** WCAG level, contrast ratios, touch targets
- **Prose:** Keyboard navigation, screen reader support, inclusive design

## 10. Icons
- **Tokens:** Icon set, stroke weight
- **Prose:** Icon style guidelines, size rules, usage patterns

## 11. Imagery
- **Tokens:** Image styles, aspect ratios
- **Prose:** Photography direction, illustration style, placeholder strategy

## 12. Content Voice
- **Tokens:** Tone descriptors, formality level
- **Prose:** Writing style, terminology, microcopy guidelines
