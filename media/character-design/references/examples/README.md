# Character-design examples

These files are bundled pattern references for the `character-design` skill. They demonstrate the expected paste-ready prompt structure, section order, concise phrase style, composite-sheet layout, and continuity level.

The current user brief is always the primary context. Use an example only to understand format and level of specificity. Never copy an example's project name, character identity, palette, props, layout decisions, dialogue, or visual details into a new prompt unless the user explicitly requests that detail.

Before writing a prompt:

1. extract the user's resolved facts and constraints;
2. choose the closest example only as a structural guide;
3. adapt every section to the user's brief;
4. omit unsupported details rather than filling gaps from an example;
5. run the full `SKILL.md` quality gate, including the output-vocabulary scan.

Every prompt-example file in this directory uses this exact top-level skeleton:

1. opening keyword stack;
2. `ASPECT RATIO:`;
3. `PROJECT:`;
4. `CHARACTER IP DESIGN`;
5. `SUBJECT:`;
6. `MAIN CHARACTER:` or `MAIN SUBJECT:`;
7. `OUTFIT DESIGN:` with `Top body:` and `Lower body:` when applicable;
8. `PROPS:` or `EQUIPMENT:`;
9. `LAYOUT STRUCTURE:`;
10. `VISUAL DETAILS:`;
11. `COLOR PALETTE:`;
12. `LIGHTING:`;
13. `CAMERA:`;
14. `MOOD:`;
15. `LAYOUT:`;
16. `QUALITY:`;
17. `AVOID:`.

Only the section content varies between examples. `README.md` explains this contract and is not itself a prompt example. The examples are internal companions and do not replace the skill instructions or the user's brief.
