# Worked-example decisions

Read alongside [the complete SRT](clouds-have-water-why-doesnt-it-always-rain.srt) and [the evidence record](clouds-have-water-why-doesnt-it-always-rain.source.md). This commentary belongs in the learning bundle, never in a delivered narration file.

## Brief to narrative

The title asks a familiar question. The opening uses an ordinary scene and sets a concrete route. It does not invent a person, location, measured event, or experiment. The evidence record explicitly identifies the puddle as illustration.

The outline follows dependencies: surface processes, atmospheric movement, cloud development, precipitation growth, lifting conditions, and the surface/subsurface consequences. This is an explanation with a geographic scale change, not a list of definitions. Definitions appear where they help the mechanism.

The rain question has an answer before the last minute. The later ground sequence adds consequences rather than delaying the answer. It is a substantive extension of the original topic, useful for meeting the default duration without repeating the same cloud description.

## How the source work changed the prose

Source distinctions determined wording. Conditional processes remain conditional. General mechanisms are not presented as observations of supplied footage. The example does not promote one growth pathway into the only pathway or turn a general tendency into a guarantee.

The claim map covers the opener and conclusion as well as the body. Its short claim labels are an index to the full final blocks, not a substitute for checking those blocks. Revisions must update timecodes and affected support.

## Language and density

The script contains occasional questions implied by the title, but does not ask a fresh rhetorical question at every turn. Technical names appear with an immediate explanation. Concrete verbs do most of the work. The ending resolves the opening observation once, without a separate motivational speech.

Not every sentence adds a statistic. Explanations, necessary qualifications, and links between scales are useful information. The approach reduces the mental load while preserving a continuous factual progression.

## Timing

The final endpoint is 08:35.000, safely above the eight-minute default. Blocks last about twenty seconds and carry substantial narration. Gaps are short; they offer editorial breathing room instead of padding. Validate the actual file for word and rate estimates rather than trusting these descriptions.

The timecodes represent intended recording intervals. A narrator's performance, pronunciation choices, or visual edit can change them. If the performance differs, retime the script to the recording. Do not add silence solely to defend the original endpoint.

## Transfer to a new assignment

Use the same discipline with a different narrative spine. A historical script needs evidence and chronology; a travel script needs spatial orientation and a purposeful route; a comparison needs consistent measures. None needs to reproduce the rain example's block count, wording, or exact proportions.
