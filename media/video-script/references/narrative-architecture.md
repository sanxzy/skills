# Narrative architecture

Read while outlining. Research is organized by sources; a script is organized by the viewer's growing understanding. The outline should answer: what changes between the start and end of this video?

## A usable beat

Each beat has a purpose, a supported claim or observation, its explanation, a visual opportunity, and a reason the next beat follows. The beat can span several timestamped blocks. These private outline labels never become deliverable headings.

For example, “cloud formation” is a topic. “Invisible vapor becomes visible droplets when moist air cools” is a beat with a change, a mechanism, and an image. “Now that the cloud exists, its droplets still need to grow before rain can reach the ground” is a consequential transition.

## Pin the story in five lines

Before choosing a structure, write the story's core as five sentences — one per slot, in plain planning prose. Never in narration form; these are not lines anyone says.

| Line | The question it answers |
| --- | --- |
| **Situation** | What is true at the start — what the viewer can see, and who or what is involved? |
| **Desire** | What does the subject need or want, or what does the viewer need answered? |
| **Conflict** | What stands in the way — the obstacle, contradiction, or complication? |
| **Change** | What shifts: new evidence, a revised reading, or a decision? |
| **Result** | What is true at the end that was not true at the start? |

Keep the five words as your search handles; the slot names travel further than any phrasing of the question.

Three constraints keep this useful rather than decorative:

- **Desire does not require a person.** On an explanatory or documentary subject, desire attaches to a documented need, a task, or the question itself: what someone is trying to achieve, or what the viewer is trying to understand. Name the need or the constraint; do not attribute a motive to a place, a process, or an institution that the sources do not document.
- **Change does not require drama.** A shift in what the evidence supports, or a different way of seeing the same thing, is enough. Do not manufacture a turning point the research does not contain.
- **Result is a difference, not a summary.** If it could be written by listing what the video covered, it is a recap. State what is now true, and name the opening state it is measured against.

### Three uses

1. **Compression test.** If the core cannot be said in five sentences, it is not settled yet. Keep compressing until each slot is one clause that carries no filler. This is the cheapest way to find out that a video has two stories fighting each other.
2. **Survives expansion.** Ten beats, twenty beats, or an eight-minute script do not need ten new ideas. They elaborate the same five. When the draft is too short, add verified depth to a line you already have; do not invent a new arc to fill the clock.
3. **Drift check.** Long drafts drift. Return to the five lines and ask which line each beat serves. A beat that serves none of them is the first candidate for cutting, and a line that no beat serves is a promise the script never keeps.

### What the five lines are not

They are not the outline, not the narration, and not section headings. The beat outline below is still required; these five sentences sit above it and never become deliverable headings. Record them in the `.source.md` file that accompanies the script, whose schema is in the [sources file contract](sources-file-contract.md), and never in the `.srt`.

The method is named because five lines is enough; it is a launchpad, not the whole video.

### Worked example

The bundled [Mawsynram documentary](../examples/hujan-melimpah-kenapa-desa-ini-bisa-kekurangan-air.source.md) — a place, not a protagonist — resolves like this:

| Line | Core |
| --- | --- |
| Situation | Mawsynram receives the highest measured rainfall on record, and daily life is built around it: grass on the roofs, bamboo shields, paths that turn to mud. |
| Desire | Residents need to shelter, learn, farm, trade, and reach services through a long wet season. |
| Conflict | Each protection fights the task it serves — rain on the roof muffles the teacher's voice, a shield must leave the hands free, and the market road still has to be reached. |
| Change | Following the water from the monsoon to the dry season changes what “wettest” means: the same rain leaves a shortage of usable water. |
| Result | An ordinary rain scene ends up readable as a managed water system with a documented community response, so the record number is no longer the point. |

Note what the lines do **not** contain: no statistic, no place-name list, no invented crisis. The rainfall figure is evidence, not a story beat. If the draft opens on the record instead of on a life organised around rain, the Situation line was ignored.

## Choose a structure because it fits

### Mechanism-led explanation

**Familiar observation → immediate answer → mechanism → complication → consequence → useful resolution.**

Use for everyday science, technology, and how things work. Answer the initial question early enough to establish trust. The rest of the video deepens the answer rather than withholding it. A complication might be an exception, a limiting factor, or a difference between a common model and reality.

An eight-minute explanation can develop through several mechanisms or one mechanism examined at different scales. It does not require an unrelated history detour to fill time.

### Chronological investigation

**Verified outcome/anomaly → relevant background → sequence of decisions → evidence/discovery → outcome → remaining uncertainty.**

Use for history and documented investigations. A brief opening glimpse of the outcome can orient the viewer, followed by a clearly signaled return to the earlier period. Track what was known at each stage; do not give historical participants knowledge they did not have. Suspense should come from unresolved evidence or real constraints, not withholding basic identity or changing facts.

If evidence does not support a scene's specific weather, dialogue, emotions, or actions, do not invent them. A reconstruction should be framed as reconstruction when relevant. Avoid graphic detail that contributes little understanding.

### Place and systems journey

**Distinctive feature → geographic constraints → history or mechanism → daily life/economy → consequences → perspective.**

Use for a country, city, remote community, or landscape. Organize destinations spatially or by a clear thematic route. Establish each move so the viewer knows where they are and why they are there. Alternate wide context with a concrete example: a map, then a harbor; a climate pattern, then how homes are heated.

Do not make every stop “one of the most beautiful,” a list of buildings, and a generic sentence about rich history. Select a detail that changes the understanding of that place. If the title promises an economic explanation, scenic touring must continue that explanation or occupy a proportionate role.

### Observational task

**Subject → concrete need → obstacle → action → observed result → wider mechanism.**

Use when real evidence or available footage documents a process: feeding young, repairing a machine, moving through terrain, conducting an experiment. The task supplies engagement. Explain just enough to make actions legible and leave space for the action itself.

A particular animal's failed hunt is not proof of a species-wide decline. A single family's choices are not a representative national statistic. Shift explicitly between individual observation and general evidence.

### Comparison

**Define the measure → introduce meaningful contrasts → apply consistent criteria → reveal tradeoffs → answer the comparison.**

Use for “which,” “best,” “most,” or “why A differs from B.” Explain whether danger means toxicity, exposure, frequency, fatality, or access to treatment. Do not hide arbitrary weights behind a scientific-sounding leaderboard. Where evidence is not comparable, explain the limitation and avoid a false winner.

## Hook design

A hook should name or clearly establish the subject, present a meaningful fact or observation, and create a reason to continue. It need not contain a question.

Make the first narration paragraph earn attention immediately. For a story about a problem, betrayal, disaster, or failure, lead with its strongest verified consequence or a concrete event that shows the stakes. Then connect that consequence to the subject and the explanation the viewer needs. Do not spend the opening on a vague description of a problem, a topic agenda, or routine biography when the evidence contains a more consequential entry point. For other subjects, choose an equally concrete discovery, task, or contrast; do not manufacture harm to fit this pattern.

In the Aldrich Ames example, the execution of at least ten intelligence sources establishes the human cost before the narrative explains his access and decisions. The consequence, his position inside the CIA, and the length of his undetected betrayal create interest without inflated casualty counts or a claim that the entire CIA stopped functioning. An opening may summarize later outcomes, but must not imply that events across several years happened at once.

- **Observable contrast:** Two surfaces receive the same rainfall but drain differently.
- **Mechanism gap:** A cloud is visible, although the vapor that formed it was not.
- **Documented consequence:** An investigation's decisive evidence arrived after a long delay.
- **Concrete task:** A parent must bring food through a narrow nest opening.

Deliver evidence soon after the hook. Avoid “you won't believe,” vague danger, an unrelated spectacle, and broad claims made only to sound surprising. Do not promise an answer that the research cannot support.

For this user's Indonesian documentary voice, establish the event or consequence before introducing a casualty count or statistical qualifier. Starting cold with “Sedikitnya...” can sound like an isolated report rather than a developing story. Keep the qualification when the number appears, but give it a clear subject and context first. This is a narration preference, not permission to remove uncertainty or inflate the figure.

## Progression and density

Use fact → explanation → context → consequence as a default, not a compulsory four-sentence template. A short block may introduce a fact; the next may explain it. A transition can carry context and prepare the consequence.

Build dependency order: the viewer needs to understand a part before its role in a system. Introduce a term when the mechanism requires it. Avoid strings of names, dates, rankings, and acronyms before establishing why any matter. Usually one main idea per block is enough; a tightly connected sequence can share a block.

Depth is more useful than enumeration. Instead of adding five more unrelated examples, examine how the chosen example works, what changes under different conditions, and what that means. When no duration was requested and the draft is too short for the eight-minute default, add verified explanatory depth, not verbal decoration. For an explicitly shorter video, select and compress the necessary beats to fit that duration.

## Transitions that do work

| Relationship | Transition function |
| --- | --- |
| Cause to result | State what the change makes possible or prevents |
| General to example | Locate a concrete case that illustrates the principle |
| Example to system | Explain which general pattern the case supports |
| Past to present | Name what persisted, changed, or remains unresolved |
| Place to place | Give a useful spatial relation and a reason for moving |
| Explanation to exception | Name the condition under which the earlier rule differs |
| Problem to response | Connect an action to the specific obstacle it addresses |

“Next, let's talk about...” can orient, but repeated announcements carry little substance. Let the last fact create the need for the next one. A gap alone does not repair a logical jump.

## Ending

Resolve the opening promise using what the video has established. A brief callback is useful if its meaning has changed. Avoid reciting every prior point, introducing an unsupported grand claim, or delivering several successive endings. A call to action is optional and must fit the user's brief.

The rain example ends with the viewer recognizing a previously invisible process in an ordinary scene. An investigation may end by distinguishing identification from justice. A comparison may end by showing why the most impressive physical capability did not determine the practical result.
